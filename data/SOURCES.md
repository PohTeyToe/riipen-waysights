## How the run was made

The answer key was committed before the pipeline ran at all. The pipeline was then built and run several times on these same six Accounts (some runs from a local fetch cache), so the scorecard checks it on pages it was developed against. It is a check, not a benchmark. The outputs in `run/` are from one final live run with no cache, at the pipeline commit in `run/meta.json`.

Tompkins County's site refused scripted requests (HTTP 403, robots.txt included) when the demo brief was written earlier on 2026-10-15. It answered 200 to every request in these runs, so it is scored as an ordinary Account.

Changes made after development runs, each a general fix rather than a per-site rule:

- Discovery read the sitemap too early and spent the budget on project pages; it now reads the sitemap only when the site's menu runs out, skips project and construction pages, and treats URLs that differ only in their query string as one page.
- Text after a `<br />` was dropped on one page (Saratoga County's contact block); it is now kept, with a test.
- lincoln.ca sends an incomplete certificate chain; TLS is now verified by the operating system's trust store, which completes the chain and still rejects bad certificates.
- PDF page picking missed table rows whose unit is in the label ("kms of local roads 255"); fixed, with a test.
- One development run judged Lincoln's 255 + 55 km as part of the network because arterial roads show as 0; the extraction prompt now says a type given as zero, or roads another government owns, doesn't break coverage.
- The brief writer is now told which numbers it may use, and not to attach a department's phone to a person.
- The New York dataset query got its own small request budget after long crawls used all 15 requests.
- In one development run the model gave Tompkins County's unit as "highway miles", and the unit check refused it, so the county's own figure dropped out and the run filled the state number without asking. The answer key caught it. The check now reads the last word of a unit, and refuses lane miles the way it refuses lane-km.
- Contacts now carry only a name and title: the phone and email the sites print belong to the department, so they go on the Account.
- Scoring compares URLs ignoring `https://`, `www.` and a trailing slash (decided after a development run listed www.warrencountyny.gov/dpw for the key's warrencountyny.gov/dpw).
